# The Skool SQL Analysis

Used SQL to analyze applications for YH education from Myndigheten för yrkeshögskolan (MYH).

The goal is to help The Skool make better decisions by looking at approved and rejected applications.

# Tools

- SQL
- Oracle Linux
- Git & GitHub

# Setup

The data comes from MYH's 2025 application round.

I used Table 3 from the Excel file and imported it into Oracle Database.

The table is called "applications".

# SQL Analysis

Used SQL queries to find information about:

- Applications in different education areas
- Approved and rejected applications
- Applications within Data/IT
- Top 5 counties with the most approved applications
- Distance and on-site education
- Education names containing AI

# Data-driven Decisions

I created four questions to help The Skool make better decisions.

## 1. Which education areas have the highest approval rate?

This shows which education areas have the highest percentage of approved applications.

It can help The Skool decide which education areas to look into.

## 2. Do distance and on-site education have different approval rates?

This compares how often distance and on-site education applications get approved.

It can help The Skool when choosing how to offer their education.

## 3. Which counties have the highest approval rate within Data/IT?

This shows which counties have the highest percentage of approved Data/IT applications.

It can help The Skool decide where to offer their education.

## 4. How many private and municipal education providers are there within Data/IT?

This compares the number of private and municipal education providers within Data/IT.

It can help The Skool understand what types of schools are offering Data/IT education.
